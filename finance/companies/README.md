# 公司调研与发布规范

本规范记录站内公司研报的固定要求。新增公司研究时，默认完成研究、生成页面并发布到本网站的「投资理财 → 公司分析」；更新已有公司时，修订同一档案或在需要保留历史版本时另建带日期的档案。版式参考现有的紫光股份、九安医疗和国恩股份页面，内容按公司实际情况调整，不机械套用结论。

## 研究与写作

1. **时点与最新信息**：标明研究截止日期、股价对应的交易日和收盘价、最新完整财报、业绩预告及重要公告。收盘价、盘中价、预告与已审计实绩必须区分；发布前重新核实可能变化的事实。
2. **公司与产业链**：说明主营产品、客户、上下游位置、核心竞争力、供需或价差周期、扩产和并购。区分已贡献业绩的业务与尚在研发、建设、认证或并表初期的业务。
3. **主营贡献**：至少列出最近完整财报各主要业务的收入、收入占比、同比、毛利、毛利贡献占比和毛利率，并说明合并分母、计算方法及无法单列的残差。若公司未披露产品级费用及归母净利润，明确写明**不能计算产品级净利润贡献**，不能把毛利当作净利润。行业、产品和地区是同一业务的不同切分，不重复相加。
4. **最新业绩详析**：拆分收入、成本、毛利、费用、营业利润、归母与扣非归母利润；分析同比及可核实的单季环比，检查经营现金流、应收、存货、资本开支、债务与少数股东权益。解释利润增长的来源、现金转化、一次性收益和持续性。只有预告时，标明未经审计以及尚无收入、现金流等完整数据。
5. **主流机构评价**：记录可核实的主要券商或研究机构名称、报告日期、评级、盈利预测、核心依据和风险假设；注明样本数量与预测时点。对照公司最新预告和自己的判断，不把卖方评级或目标价当作已发生的资金流，也不把机构预测当成公司承诺。
6. **资金流向**：优先使用交易所公开信息、龙虎榜机构专用席位和深股通席位，并注明只覆盖上榜账户；同一席位同时出现在买卖榜时去重。营业部或「知名游资」标签不等于可核实的最终账户身份。行情平台的超大单、大单、中单、小单只是按成交规模划分，不能直接称为机构、游资、散户真实净买卖。基金持仓使用披露日期明确的定期报告，不拿旧持仓推断当日持仓。
7. **同行比较与估值**：选择业务确有可比性的公司；财务指标使用同一报告期间，列收入、归母净利、利润率及比较意义。再用**同一交易日**列各家公司收盘价、总市值、市盈率TTM，适用时列市净率。说明TTM利润公式、静态/动态/滚动市盈率区别、股本或A＋H等价市值口径；市净率用归母权益，不用含少数股东权益的集团权益。对业务结构和现金质量造成的估值差异作解释，不能只因倍数低就断言低估。
8. **投资判断和策略**：给出是否值得投资的结论、主要反证、盈利与估值情景、价格条件、分批参与和退出/复核条件。情景是研究假设，更新财报或价格后应重算；风险仓位示例不能冒充个性化建议。避免把季度利润机械年化、把并购承诺直接叠加到当前盈利或把题材尚未兑现的收入提前计入。
9. **来源**：重要数字和事件尽量链接年报、半年报、季报、公司公告及交易所信息；行情与机构预测注明平台和时间。自算数据给出分子、分母和口径。对来源冲突或无法核实的数据明确标注，不猜填。

## 页面与发布流程

每家公司以一个 `finance/companies/data/*.json` 为源文件，包含 `slug`、`company`、`code`、`date`、`title`、`summary`、`verdict`、`cutoff` 和完整 Markdown `body`。正文使用清晰的小节、可横向滚动的表格与靠近数据的来源链接。报告保留分析时点和假设，历史价格不得描述为当前价格。

1. 检查仓库状态与远端，保留已有或其他人的改动；需要时先同步，再编辑公司源文件。
2. 在仓库根目录运行 `node scripts/build-companies.cjs`，生成独立报告页、公司目录和投资理财入口。检查生成内容、数据公式、链接、`git diff --check` 和实际改动文件。
3. 提交并推送到网站仓库。发布后打开公开页面，核实 HTTP 可访问且新增章节、关键数字和目录入口已经更新；GitHub Pages 有缓存延迟时稍后重试。
4. 只有线上核实成功才向用户报告「已发布」。若网络、权限或部署阻断，明确区分本地完成、已推送和线上可见三个状态，并保留可继续发布的文件与提交。

每次复盘都重新核实行情、财报、机构观点与资金数据，不复制旧报告中的「最新」结论。
